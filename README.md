# 🌿 Health Tracker

A full-stack web app to track daily health goals.

## Features
- Track water, calories, steps, and sleep
- Real-time progress messages based on goals
- Data persists using SQLite database
- Reset option to start fresh

## Tech Stack
Python · Flask · SQLite · HTML · CSS · JavaScript

## How to Run
1. Clone the repository

2. Navigate to the folder

3. Install Flask

4. Run the app

## Note
Originally built as a static HTML/CSS/JS app; upgraded with a Flask backend and SQLite database for persistent data storage.
